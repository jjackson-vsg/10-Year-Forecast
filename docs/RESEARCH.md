# Research seed: forecasts, evidence and outcomes

This repository supplies a reproducible starting snapshot and a working presentation layer. It is not a validated forecasting benchmark or a completed research study.

## Data layers

1. **Original model documents**: the four root-level Markdown files. Preserve them when adding new runs so raw outputs can be compared with later editorial interpretations.
2. **Editorial dataset**: `dist/data.js`, the canonical source used by the website. It separates the proposed trajectory, timing window, supporting evidence, caveats and signals to watch.
3. **Research export**: `research/forecast-snapshot.json`, generated by `scripts/export-data.mjs`. It contains the same records in a language-neutral format.
4. **Presentation**: the timeline, comparisons, source catalogue and explicitly imagined illustrations. Artwork does not encode observed data or measured forecast likelihoods.

## JSON structure

| Field | Meaning |
| --- | --- |
| `schemaVersion` | Export format version; currently 1 |
| `snapshot` | Human-readable research snapshot date |
| `originalForecastRevision` | Git revision identifying the original inputs |
| `models[]` | Repository labels, source filenames/URLs, stance, strengths and caveats |
| `sources{}` | Evidence records keyed by source ID, including organisation, date, type, URL and explanatory note |
| `years[]` | Ten annual chapters with summary, signal, watch criteria, four model takes and three editorial events each |
| `years[].takes[]` | Paraphrases in the order given by `models[]`; not raw output quotations |
| `years[].events[]` | `id`, `topic`, `title`, `summary`, `confidence`, `window`, `why`, `evidence`, `watch`, `caveat`, `refs`, `origin` |
| `comparisons[]` | Nine topics, four model takes, synthesis verdict and supporting source IDs |

Event `refs` point to keys in `sources`. Event `origin` points to model IDs. Confidence labels are qualitative judgements about direction, not numeric probabilities. Windows may span several years or remain open-ended.

## Reproduce or extend the dataset

Read the checked-in JSON directly, for example:

```python
import json
from pathlib import Path

snapshot = json.loads(Path('research/forecast-snapshot.json').read_text(encoding='utf-8'))
events = [dict(event, chapter_year=year['year'])
          for year in snapshot['years']
          for event in year['events']]
print(len(events))  # 30
```

When changing the canonical JS dataset, regenerate the JSON with `npm run export:data` and commit both changes together. The exporter is deterministic: it does not fetch sources, call a model or silently change the snapshot date.

For additional research runs, record the exact prompt, run date, provider/model identifier where verifiable, parameters, raw output, refusals and retrieval/source inputs. Keep these separate from later editing and scoring. A refused response is missing forecast data, not an implied position.

Before evaluating outcomes, make each claim operational: define what counts as success, the geography/population, the time window, the outcome source and how partial fulfilment will be handled. Predefine the scoring approach. Do not convert the existing High/Medium/Speculative labels into invented percentages or infer calibration from agreement between four models.

## Limits of this starting snapshot

- Model names/versions are repository labels, not independently authenticated provider identities. Astra's document uses “Nova”; Fable's uses “Claude”.
- The originals are not independent draws from a calibrated statistical ensemble. Shared data and assumptions can produce correlated errors.
- Later-year positions are narrative waypoints. The explicit event window is the intended timing range.
- Source links support the specific evidence attached to them. A company roadmap or government target is evidence of intent, not proof of future delivery.
- The evidence snapshot is dated 16 September 2026. This export preserves it; it does not revalidate or update every external publication.
- Coverage favours AI, richer economies and US–China competition. Regional and distributional blind spots remain.
- GLM 5.3 and DeepSeek refusals/thread locks are a user-reported observation, not independently verified. Their cause and any withheld forecast are unknown. They are not counted in the four-model comparison.

The existing Apache 2.0 licence remains in place. Keep source attribution and distinguish repository material from linked third-party publications when extending the work.
